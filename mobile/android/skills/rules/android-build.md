# Android build standards (Gradle, AGP, R8)

Severity tags as in the core rules: **blocker**, **major**, **minor**, **nit**. Never raise Kotlin, AGP, Gradle, an SDK level or the Compose BOM beside other work; that is its own `migration` move. *major*

- On AGP 9, `org.jetbrains.kotlin.android` is not applied; Kotlin is built in. *blocker*
- The AGP 9 opt-outs (`android.builtInKotlin=false`, `android.newDsl=false`, `legacy-kapt`) are not set, or carry a dated removal task. *major*
- Annotation processors use KSP, never kapt. *major*
- `compileSdk`, `targetSdk` and `minSdk` are written explicitly, never left to a default; `targetSdk` rises one level at a time, in its own change. *major*
- A JDK 21 toolchain is declared in Gradle, not assumed from the IDE. *major*
- Every version lives in `libs.versions.toml`; Compose comes through the BOM; no hard-coded version or `buildSrc` constants object. *minor*
- Release builds are minified and shrunk with R8 full mode; never `android.enableR8.fullMode=false` as a fix. *major*
- Keep rules are narrow and carry a reason; no `-keep class ** { *; }`. *major*
- Release ships a Baseline Profile and a Startup Profile, generated by the plugin and proven by a Macrobenchmark on a non-debuggable build; the mapping file is uploaded with every release. *major*
- ktlint fails the build on any violation, and no formatter, detekt or Lint auto-fixes inside a build phase. *minor*
- `[KMP]` A shared module on AGP 9 applies `com.android.kotlin.multiplatform.library`, never `com.android.library` beside the multiplatform plugin; the app is its own `com.android.application` module. *blocker*
- `[KMP]` KSP is configured per target; Hilt and Dagger are never a shared module's dependency. *major; blocker for Hilt*

## Enforced by the build

| House rule (file, section) | Tool | Rule id or setting | Level |
|---|---|---|---|
| Lint fails the build (`android-build.md`) | Android Lint | `warningsAsErrors = true` and `abortOnError = true` in `lint { }` | setting |
| detekt fails the build (`android-build.md`) | detekt | `build: maxIssues: 0` in `detekt.yml` | setting |
| No `!!` outside tests (`android.md`, Kotlin) | detekt | `UnsafeCallOnNullableType` | error |
| No `GlobalScope` (`android.md`, Coroutines and the main thread) | detekt | `GlobalCoroutineUsage` | error |
| No `runBlocking`, and no `Thread.sleep` in production code or in a test (`android.md`, Coroutines and the main thread; `android-tests.md`) | detekt | `ForbiddenMethodCall` for `kotlinx.coroutines.runBlocking` and `java.lang.Thread.sleep`; `SleepInsteadOfDelay` | error |
| Dispatchers are injected, never named in a class body (`android.md`, Coroutines and the main thread) | detekt | `InjectDispatcher` | error |
| No `runCatching` around a suspend call, which swallows `CancellationException` (`android.md`, Coroutines and the main thread) | detekt | `SuspendFunSwallowedCancellation` | error |
| Never `collectAsState()` on a ViewModel flow (`android.md`, Coroutines and the main thread) | detekt | `ForbiddenMethodCall` for `androidx.compose.runtime.collectAsState` | error |
| No `catch { }` that leaves a region empty (`android.md`, Errors, secrets and untrusted input) | detekt | `EmptyCatchBlock` | error |
| A `PendingIntent` is immutable (`android.md`, Errors, secrets and untrusted input) | Android Lint | `UnspecifiedImmutableFlag` | error |
| An `Intent` is never launched from unchecked intent data (`android.md`, Errors, secrets and untrusted input) | Android Lint | `UnsafeIntentLaunch` | error |
| An exported `ContentProvider` or `Service` has a permission (`android-manifest.md`) | Android Lint | `ExportedContentProvider`, `ExportedService` | error |
| TLS only: no cleartext in the base config, no user CA outside `<debug-overrides>` (`android-manifest.md`) | Android Lint | `InsecureBaseConfiguration`, `AcceptsUserCertificates` | error |
| Wake locks are bounded (`android-platform.md`, Background work) | Android Lint | `WakelockTimeout` | error |
| No `notifyDataSetChanged` (`android-views.md`) | Android Lint | `NotifyDataSetChanged` | error |
| Layouts carry no hard-coded text or `px`; actionable images have a `contentDescription` (`android-views.md`) | Android Lint | `HardcodedText`, `PxUsage`, `ContentDescription` | error |
| `modifier` is the first optional parameter (`android-ui.md`) | Android Lint, from `androidx.compose.ui` | `ModifierParameter` | error |
| Side effects run only in the effect APIs (`android-ui.md`) | Android Lint, from `androidx.compose.runtime` | `CoroutineCreationDuringComposition` | error |

A row the project's config does not enforce is *minor*.

Turning a row off to pass a gate is *major* (`engineering:quality-constraints`).

How the rows are wired:

- Each detekt `error` row is `active: true` in `config/detekt/detekt.yml`, and `build: maxIssues: 0` makes any finding fail `detekt`. The default config already skips `UnsafeCallOnNullableType` in test sources, so `!!` is allowed there; `ForbiddenMethodCall` is not skipped in tests.
- Five detekt rows need type resolution: `UnsafeCallOnNullableType`, `InjectDispatcher`, `SleepInsteadOfDelay`, `SuspendFunSwallowedCancellation` and `ForbiddenMethodCall`. The `detekt` task skips them without a failure when it has no `classpath`, and detekt 1.23.8's Gradle plugin registers no per-variant task on AGP 9, so the build file sets `classpath` and `jvmTarget` on the task (block below).
- detekt reads `src/main` and `src/test` only, so KSP, Room and Hilt output under `build/generated` is never linted. Android Lint skips generated sources too (`checkGeneratedSources` is off by default): a flag-less `PendingIntent` in a generated file is not reported.
- Each Android Lint `error` row is `<issue id="…" severity="error" />` in the committed `lint.xml`, set in `lint { lintConfig = file("lint.xml") }`, so it fails `lintDebug` on its own. `warningsAsErrors = true` also fails on every default warning (`GradleDependency`, `OldTargetApi`, `UnusedResources`); a baseline covers the findings that already exist, never a new one.
- `ModifierParameter` and `CoroutineCreationDuringComposition` come from the lint jars of the Compose libraries and run only in a module with that dependency. No Lint check reads `usesCleartextTraffic="true"`: that manifest line stays a review finding.
- A suppression carries its reason: `@Suppress("RuleId")` for detekt, `@SuppressLint("Id")` for Lint.

`config/detekt/detekt.yml`:

```yaml
build:
  maxIssues: 0
coroutines:
  GlobalCoroutineUsage:
    active: true
  InjectDispatcher:
    active: true
  SleepInsteadOfDelay:
    active: true
  SuspendFunSwallowedCancellation:
    active: true
potential-bugs:
  UnsafeCallOnNullableType:
    active: true
empty-blocks:
  EmptyCatchBlock:
    active: true
style:
  ForbiddenMethodCall:
    active: true
    methods:
      - value: 'kotlinx.coroutines.runBlocking'
        reason: 'Blocks the calling thread'
      - value: 'java.lang.Thread.sleep'
        reason: 'Use delay in a coroutine'
      - value: 'androidx.compose.runtime.collectAsState'
        reason: 'Use collectAsStateWithLifecycle'
```

`app/build.gradle.kts`, the type-resolution wiring:

```kotlin
val androidComponents = extensions.getByName("androidComponents") as AndroidComponentsExtension<*, *, *>

androidComponents.onVariants(androidComponents.selector().withName("debug")) { variant ->
    tasks.withType<Detekt>().configureEach {
        jvmTarget = "21"
        classpath.setFrom(
            androidComponents.sdkComponents.bootClasspath,
            variant.compileConfiguration.incoming.artifactView {
                attributes { attribute(Attribute.of("artifactType", String::class.java), "android-classes-jar") }
            }.files,
        )
    }
}
```
