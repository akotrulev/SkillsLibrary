# Android build standards (Gradle, AGP, R8)

Severity tags as in the core rules: **blocker**, **major**, **minor**, **nit**. Never raise Kotlin, AGP, Gradle, an SDK level or the Compose BOM beside other work; that is its own `migration` move. *major*

- On AGP 9, `org.jetbrains.kotlin.android` is not applied; Kotlin is built in. *blocker*
- The AGP 9 opt-outs (`android.builtInKotlin=false`, `android.newDsl=false`, `legacy-kapt`) are not set, or carry a dated removal task. *major*
- Annotation processors use KSP, never kapt. *major*
- `compileSdk`, `targetSdk` and `minSdk` are written explicitly, never left to a default; `targetSdk` rises one level at a time, in its own change. *major*
- A JDK 21 toolchain is declared in Gradle, not assumed from the IDE. *major*
- Every version lives in `libs.versions.toml`; Compose comes through the BOM; no hard-coded version or `buildSrc` constants object. *minor*
- Release builds are minified and shrunk with R8 full mode; never `android.enableR8.fullMode=false` as a fix. *major*
- Keep rules are narrow and carry a reason; no `-keep class ** { *; }`. *major*
- Release ships a Baseline Profile and a Startup Profile, generated by the plugin and proven by a Macrobenchmark on a non-debuggable build; the mapping file is uploaded with every release. *major*
- detekt, ktlint and Lint run with warnings failing the build; none auto-fixes in a build. *minor*
- `[KMP]` A shared module on AGP 9 applies `com.android.kotlin.multiplatform.library`, never `com.android.library` beside the multiplatform plugin; the app is its own `com.android.application` module. *blocker*
- `[KMP]` KSP is configured per target; Hilt and Dagger are never a shared module's dependency. *major; blocker for Hilt*
