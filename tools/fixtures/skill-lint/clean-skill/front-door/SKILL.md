# Front door

The guide is [here](references/guide.md); the long one is `references/long-guide.md`. A pattern
such as `references/<topic>.md` is not a pointer, and a skill that says "remove `TODO` markers"
names the marker. The plugin's rule files are `rules/` (a folder name, not a pointer).
