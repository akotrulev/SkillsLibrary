# Security — audit fragment (section K)

Rows `K1…` are permanent. A platform's conformance checklist section **K — Security** holds no rows of its own: it takes the rows below whose `Platforms` column names its platform (`macos`, `windows`), and a finding `K3` is row K3 here. Append new rows at the end with the next number; never renumber.

**How to read a row.** *Check* = the invariant. *Violation looks like* = what disqualifies it. *Find it with* = a mechanical lead — a hit is never a finding until the code is read. *Sev* = default severity (blocker — a hard security break per the severity anchors). *DA* = the OWASP Desktop App Security Top 10 (2021) id. A row marked **requires dynamic test → `qa-security`** cannot be proven from source: report it **unverified**, never passed. Every K report ends with the carve-out line from `SKILL.md`.

Recipes use `rg`. Globs: `macos` → `*.swift,*.plist,*.entitlements,*.xcconfig`; `windows` → `*.cs,*.xaml,*.csproj,*.appxmanifest,*.cpp,*.h,*.idl,*.vcxproj`. Lane tags go in brackets: `[MAS]`, `[DevID]`, `[packaged]`, `[unpackaged]`, `[WinUI]`, `[WPF]`, `[WinForms]`, `[C++]`, `[AppKit]`.

## What a source read cannot prove

| Claim | Why static fails | Handed to |
|---|---|---|
| Entitlements, capabilities and hardened-runtime flags of the **signed** app | The build setting and the signed artifact can differ | `qa-security` |
| Which library a live process loaded; DLL planting resistance | Depends on the working directory, `PATH` and ACLs at run time | `qa-security` |
| XPC / named-pipe peer rejection, pipe DACL as installed | Behavioural, per machine | `qa-security` |
| What the Keychain, vault or DPAPI really stored and who can read it | Config says where, not what | `qa-security` |
| TLS validation and pinning on the wire | Needs an interception proxy | `qa-security` |
| Bridge and activation handlers reject hostile input | Needs crafted URLs, files and messages | `qa-security` |
| Update verification rejects a tampered package | Needs a hostile feed | `qa-security` |
| Binary hardening flags (ASLR, CFG, CET, canaries) | Properties of the built artifact | `qa-security` |
