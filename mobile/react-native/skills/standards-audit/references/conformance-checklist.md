# mobile-react-native Conformance Checklist — the 23 sections

The audit's spine. Section letters and check numbers are **permanent** — a finding is `<letter><n>` (`B3`, `M1`) and keeps that ID across every round, forever. Never renumber; append new checks at the end of a section with the next free number. The letters are identical on all three mobile stacks (`react-native`, `ios`, `android`): `M` is Accessibility everywhere.

**How to read a row.** *Check* = the invariant. *Violation looks like* = what disqualifies it. *Find it with* = a mechanical lead (a grep hit is never a finding — read the code). *Sev* = the default severity; adjust for real impact and say why.

**Recipes** use `rg` (ripgrep), which honours `.gitignore` — so `node_modules/`, `ios/`, `android/` (generated by prebuild), `.expo/`, `dist/` and `coverage/` are skipped without flags. Without ripgrep, `grep -rn --include='*.ts' --include='*.tsx' --exclude-dir=node_modules --exclude-dir=ios --exclude-dir=android` is equivalent. Set the source roots once:

```bash
SRC=$(ls -d app src components 2>/dev/null | tr '\n' ' ')   # adjust to the repo layout
rg -n "<pattern>" $SRC -g '*.ts' -g '*.tsx'                      # the shape every recipe below uses
```

If the repo gitignores a generated native folder (`ios/`, `android/` under CNG) you still need to read, add `--no-ignore` and exclude it explicitly — and say so in the report's coverage line.

**The version lane gates everything.** Before flagging, confirm the check applies to the detected Expo SDK (57 primary, 58 next, 55–56 supported, 54 floor), whether the project is Expo Router or bare React Navigation, and whether the React Compiler is on. Rows tagged **[SDK58]** and **[bare]** apply only in that lane.

**Fragment sections.** K, L, T, U and X carry no rows here: their rows live in `mobile/_shared/<skill>/references/audit-checks.md` and are filtered by the `Stacks` column. Every other section is filled by the task that writes its skill — an empty section means that skill is not written yet, not that the code passes.

**Severity.** blocker — ships a crash, a store rejection, or a hard security rule break. major — a rule in CLAUDE.md § Mobile code rules broken where it will hurt soon. minor — style, naming, a single missing label. nit — preference.

## V — Comments & KISS
*Owning skills: [`ep-code-comments`](../../../../../engineering-practices/code-comments/SKILL.md) · CLAUDE.md § Comments and § Simplicity (KISS)*

| # | Check | Violation looks like | Find it with | Sev |
|---|---|---|---|---|
| V1 | No inline comments in a body | A `//` line inside a function or method body — a step marker, a restatement of the next line, a section banner | `rg -n "^\s+//\s" $SRC -g '!*.d.ts'` | minor |
| V2 | A doc comment states a contract, not the signature | A doc comment that restates the name or signature (`Returns the user id`, `@param id the id`) on a property, DTO, getter or single-expression function | `rg -n -B1 "^\s*\* @(returns?\|param)\b" $SRC` | minor |
| V3 | No commented-out code, no `TODO` / `FIXME` left behind | A `//` line holding code, or a `TODO` / `FIXME` / `HACK` marker in committed source | `rg -n "^\s*//\s*(const\|let\|import\|return\|if\|await\|export)\b" $SRC` · `rg -n "TODO\|FIXME\|HACK" $SRC` | minor |
| V4 | A comment that exists because the code is unclear | A comment explaining what a badly named local or method does — the fix is the rename or extraction, not a reworded comment | Read the comment hits from V1; ask whether a name would carry it | major |
| V5 | No `interface`/`type` with one implementer | An abstraction introduced for one caller and one implementation, with no second real need | `rg -n "^(export )?interface \w+" $SRC`; then count implementers per hit | major |
| V6 | No wrapper that only forwards | A class or function whose whole body delegates one call to the next layer (service → repository → ORM as three layers) | `rg -n "=>\s*\w+\.\w+\(\.\.\.args\)\|return \w+\.\w+\(\w+\);?\s*}" $SRC`; read each hit for a single delegated call | major |
| V7 | No configurability nothing uses | An options bag, flag, generic parameter or extension point that no caller passes or varies | `rg -n "options\??:\|\bopts\b\|config\??:" $SRC`; then search for a call site that supplies it | major |
| V8 | A generated or scaffolded comment is removed | A template header, a framework placeholder comment or a wizard banner left in a source file, with no tool depending on it | `rg -n "Created by\|Generated by\|This file was\|Copyright \(c\)" $SRC` — skip a generated native folder (`ios/`, `android/` under CNG) | minor |
